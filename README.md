
 🛠️ Windows Maintenance Automation Script

## 📌 Overview
This project is a Windows batch script designed to automate routine maintenance tasks commonly performed in IT support environments.

It helps improve system performance, reduce manual work, and standardize maintenance procedures.

---

## ⚙️ Features

- Cleans temporary files from the system
- Logs deleted files and folders
- Lists Recycle Bin contents
- Clears Recycle Bin using PowerShell
- Opens Windows Update
- Starts update scan automatically

---

## 🖥️ Technologies Used

- Batch Script (.bat)
- PowerShell
- Windows

---

## 🚀 Use Case

Useful for IT support and help desk automation.
